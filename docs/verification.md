# 真机验收清单

> 当前状态：**未验证**。下列任一项完成后，请在 issue 里附设备与版本信息。

## 环境

| 项 | 值 |
|---|---|
| 手机 App | MeowFace（记录版本号） |
| 系统 | Windows 10 / 11 x64 |
| 宿主 | FaceGaze Bridge（记录版本号） |
| 网络 | 手机与 PC 在同一网段 |

## 步骤

- [ ] 手机 MeowFace 填 PC 的局域网 IP，端口默认 12345
- [ ] PC 上关闭 VRCFT 及其它占用 12345 的程序
- [ ] FGB「模块库 → 原生模块」安装 `meowface-<版本>.zip`
- [ ] 「模块」页把 MeowFace 设为启动，重启引擎
- [ ] 模块卡片显示活跃，状态页有表情输入

## 观察项

- [ ] 张嘴 → `JawOpen`
- [ ] 微笑 → 嘴角上扬 + CheekSquint 近似项
- [ ] 眨眼 → 睁眼度下降，左右眼独立
- [ ] 转头 → 表情不跟随头部移动
- [ ] 遮挡摄像头 / 离开网段 → 10 秒内卡片给出「已 N 秒没有数据」
- [ ] 恢复后自动回到活跃
